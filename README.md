## 🌟 Key Architecture Modules

1. **One Ecosystem Core (Reference-Lock 2)**:
   - 3D exploded modular engine featuring 4 synchronized quadrants: Inventory, Support, Analytics, and Automation.
   - Interactive perspective angles and real-time state telemetry.

2. **SellsVora Mobile CRM Showcase (Reference-Lock 1)**:
   - Floating 3D perspective smartphone chassis with multi-layered glass depth cards.
   - Sub-50ms offline database synchronization, interactive cursor tilt, and dynamic stock inspection.

3. **Neural Sales Conduit Simulator (Reference-Lock 3)**:
   - Industrial titanium chassis with illuminated acrylic tubing routing data pulses.
   - Autonomous skills: Inbox Skill, CRM Reconciliation, Outbound Prospecting, and Real-time Voice Call Coaching.

4. **Product Hub & Capability Blueprint**:
   - Comprehensive catalog covering SAMX OmniCore ERP, SellsVora, and AI automation conduits.
   - The 6-step Continuum: *Problem → Bespoke Service → Reusable Module → Software Product → SaaS → Proprietary IP*.

5. **Operations & ROI Engines**:
   - Live node latency telemetry across Riyadh HQ, South Asia Hub, and GCC edge gateways.
   - Interactive financial audit calculator quantifying annual capital preserved in SAR & USD.

6. **Multilingual Architecture**:
   - Native RTL support for Arabic (`العربية`) and Urdu (`اردو`), plus English.

## 🚀 Deployment to Vercel / Netlify

This project is a standalone Single Page Application (SPA) powered by Vite:

```bash
# Install dependencies
npm install

# Run local development server
npm run dev

# Build production bundle
npm run build
```

### Vercel Deployment Settings:
- **Framework Preset**: `Vite`
- **Build Command**: `npm run build`
- **Output Directory**: `dist`
- **Install Command**: `npm install`
